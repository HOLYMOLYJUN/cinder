# 플레이 스토어 등록 자료

Play Console 폼에 그대로 옮겨 적으라고 모아 둔 것. 초안이므로 마음에 안 드는 문장은 고쳐 쓴다.

## 앱 이름

```
잿불
```

> 30자 이내. 「잿불 — 불씨를 들고 오르는 탑」 처럼 늘려도 되지만, 목록에서 뒤가 잘린다.
> 짧은 쪽이 낫다.

## 짧은 설명 (80자)

```
불씨 하나를 들고 열다섯 층을 오릅니다. 탑은 매일 새로 섭니다.
```

다른 안:

```
어둠 속에서 불씨가 닿는 곳만 보입니다. 죽으면 기억 하나가 남습니다.
```

## 자세한 설명 (4000자)

```
불씨를 들고 탑을 오르는 턴제 로그라이크입니다.

불씨가 닿는 곳만 보입니다. 지나온 자리는 차갑게 식은 기억으로 남고,
그 너머는 어둠입니다. 불을 키우면 멀리 보이지만, 몬스터도 당신을
더 멀리서 알아챕니다.

한 판은 스무 분 남짓입니다. 죽으면 모은 것은 사라지지만
「기억」 하나가 남아 다음 판으로 건너갑니다.


■ 매일 새로 서는 탑

탑의 지형은 날짜로 정해집니다. 오늘 당신이 오르는 열다섯 층은
오늘 다른 사람이 오르는 것과 같은 층입니다.


■ 층에 남는 흔적

먼저 오른 사람이 쓰러진 자리와 벽에 남긴 쪽지가 층에 나타납니다.
접속해 있지 않아도 됩니다. 이 탑은 원래
「이름을 적으면 올라갔고, 아무도 내려오지 않았다」는 곳입니다.


■ 골라 잡는 다섯 사람

기사·엘프·마법사·리자드·드워프. 시작 스탯이 다르고
싸우는 방식이 다릅니다. 마법사는 처음부터 마법으로 싸웁니다.


■ 들어 있는 것

· 몬스터 21종과 보스 3종 — 예고를 보고 피해야 하는 기술
· 장비 21종 3등급, 접두사가 붙는 정체불명 아이템
· 기억 9종 — 판을 넘어 남는 성장
· 레벨과 경험치 — 이 판에서만 사는 성장
· 안식처의 모닥불과 상인, 골드를 쓰는 대장장이
· 11층부터 바뀌는 지형
· 두 갈래 결말
· 도감 — 마주친 것만 열립니다
· 이어하기 — 앱을 닫아도 하던 층에서 그대로


■ 없는 것

· 광고
· 앱 내 구매
· 회원가입과 로그인
· 인터넷 연결 (흔적을 볼 때만 씁니다. 없어도 끝까지 할 수 있습니다)


웹에서도 같은 게임을 할 수 있습니다: https://cindertower.com
```

> 「없는 것」 목록이 실제로 사람을 붙잡는다. 요즘 스토어에서 저 넷이 다 없는 게임은 드물다.

### 스크린샷

```
npm run app:shots        → docs/store/*.png
```

에뮬레이터에서 손으로 찍지 않는다. `tools/make-store-shots.js` 가 `dist/app/index.html`
— 스토어에 올라가는 바로 그 파일 — 을 폰 크기 창에 띄우고 장면을 하나씩 세워서 찍는다.
같은 명령이 언제나 같은 일곱 장을 뱉으므로, 게임이 바뀌면 다시 돌리기만 하면 된다.

파일 이름의 번호가 **Play Console 에 올리는 순서**다:

| 2 | `02-marks.png` | 남이 남긴 쪽지와 죽은 자리 — 이 게임에만 있는 것 |

| 4 | `04-gear.png` | 장비 비교 — 공격을 버리고 주문을 얻을까 |

**맨손에 빈 로그로 찍지 말 것.** 아직 아무것도 없는 게임처럼 보인다.
그래서 도구가 장비를 들리고 로그를 채우고 도감을 열어 둔 채로 찍는다 —
장면을 지어내는 것이 아니라, 몇 층 올라온 사람의 화면을 그대로 세우는 것이다.

## 데이터 안전 (Data safety) 신고

**앱이 실제로 보내는 것은 「흔적」 하나뿐이다.** 채팅은 앱 빌드에서 꺼져 있다
(`NET.CHAT=false`). 광고·분석 도구·결제는 없다. 권한은 `INTERNET` 하나뿐이다.

### 서버로 나가는 값 (`POST /marks/add`)

| 값 | 무엇 | 신원을 알 수 있나 |
|---|---|---|
| `uid` | 기기에서 만든 무작위 12자. `crypto.getRandomValues` | 아니오 — 계정·기기 식별자와 무관 |
| `day` | 날짜 (오늘의 탑 시드) | 아니오 |
| `floor` `x` `y` | 층과 좌표 | 아니오 |
| `kind` | `grave` 또는 `note` | 아니오 |
| `a` `b` | 쪽지 낱말 **번호 둘**. 문장이 아님 | 아니오 |
| `killer` `turns` | 무엇에게 쓰러졌나, 몇 턴 버텼나 | 아니오 |
| `by` | 표시 이름 — **앱에서는 언제나 「누군가」** | 아니오 |

여기에 더해 모든 HTTP 요청이 그렇듯 **IP 주소**가 서버(Cloudflare)에 닿는다.

### 폼에 답할 내용 (권장안)

| 질문 | 답 |
|---|---|
| 데이터를 수집·공유하는가 | **예** |
| 어떤 유형 | **기기 또는 기타 ID** — 앱이 만든 무작위 식별자(`uid`) |
| | **앱 활동 → 기타 사용자 생성 콘텐츠** — 흔적(층·좌표·낱말 번호) |
| 목적 | **앱 기능** (다른 사람의 흔적을 보여주기 위해) |
| 필수인가 선택인가 | **선택** — 인터넷 없이도 게임이 끝까지 돌아간다 |
| 제3자와 공유하는가 | **아니오** (같은 게임을 하는 다른 사용자에게 표시되는 것은 「공유」가 아니라 앱 기능) |
| 전송 중 암호화되는가 | **예** (HTTPS) |
| 삭제를 요청할 수 있는가 | **예** — 개인정보처리방침에 절차를 적어 두었다 |

> ⚠️ 위는 코드를 그대로 읽고 정리한 **권장안**이지 법적 판단이 아니다.
> 폼의 각 항목에는 구글이 붙여 둔 설명이 있으니, 옮겨 적기 전에 한 번씩 읽고
> 우리 값이 정말 그 칸에 맞는지 확인할 것.

### 그 밖의 폼

| 질문 | 답 |
|---|---|
| 광고가 있는가 | **아니오** |
| 앱 내 구매 | **없음** |
| 타겟 연령층 | **아동 대상 아님** (13세 미만을 겨냥하지 않음) |
| 콘텐츠 등급 설문 | 판타지 폭력 **있음**, 피 표현 없음, 성적 내용 없음, 도박 없음, 사용자 간 소통 **없음**(앱 기준) |
| 개인정보처리방침 URL | `https://cindertower.com/privacy.html` |

> 「사용자 간 소통」에 **없음**으로 답하는 근거는 앱 빌드에 채팅이 없기 때문이다.
> 흔적은 정해진 낱말의 번호만 오가므로 자유로운 소통 수단이 아니다.
> 나중에 앱에 채팅을 켠다면 이 답을 반드시 바꿔야 한다.
