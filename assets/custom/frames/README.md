# dragon — 손질해서 뽑은 프레임

`assets/custom/dragon_opacity2.png` 에서 뽑아 이 프로젝트 규격에 맞춘 것.
다시 만들려면 `python make-dragon.py`.

## 결과

| 파일 | 크기 | 색 |
|---|---|---|
| `dragon_idle_anim_f0..f3.png` | 32x36 | 6 |
| `dragon_run_anim_f0..f3.png` | 40x36 | 6 |

합쳐서 5.2KB. 이름은 `tools/pack-sprites.js` 의 `frames()` 규칙(`<이름>_idle_anim_fN`)에 맞췄다.

## 규격을 어디에 맞췄나

기존 큰 몬스터(`big_demon`, `ogre`, `big_zombie`)를 재서 따라갔다.

- **32x36** — troll·golem·bigdemon 과 같은 판. run 은 날개를 펴서 40 폭이 필요했다.
- **idle 4장 + run 4장** — 이 프로젝트 몬스터는 예외 없이 이 구성이다.
- **색 6개** — 0x72 팔레트에서만 골랐다. big_demon 이 4색, ogre 가 6색이다.
- 색 비율 38/25/22/8/5/2 (검정이 가장 많다). ogre 가 33/22/20/12/10/2, big_demon 이 57/21/17/5.

쓴 색: `(34,34,34)` 외곽선 · `(98,35,47)` 어두운 붉은색 · `(159,41,78)` 중간 ·
`(218,78,56)` 밝은 붉은색 · `(216,165,125)` 황갈 · `(252,203,163)` 크림. 전부 0x72 팔레트 색.

## 어떻게 만들었나

원본은 도트가 아니라 **안티에일리어싱이 잔뜩 낀 그림**이었다 (색 188,818개, 알파 없음,
흰 체커 배경이 그림으로 그려져 있음). 다만 **4px 격자로 확대한 흔적**이 남아 있어서
(세로 엣지의 34.6%가 4의 배수 위치, 무작위면 25%) 그걸 되돌리는 식으로 복원했다.

1. **복원** — 4x4 블록마다, 시트 왼쪽 위 견본에서 뽑은 14색 중 **최빈색으로 투표**해 1픽셀로. 밝은 배경은 투명 처리.
2. **6색 대응** — 14색을 명도 사다리에 맞춰 0x72 6색으로 손으로 짝지었다.
   명도를 무시하고 최근접색으로 자동 변환하면 어두운 붉은색이 `(159,41,78)` 자홍으로 몰려 분홍빛이 된다.
3. **노이즈 정리** — 같은 색 이웃이 1개 이하인 픽셀을 주변 다수색으로 흡수.
   단 **밝은 색(뿔·배)은 완전히 고립됐을 때만** — 안 그러면 뿔이 검정에 먹힌다.
4. **외곽선** — 실루엣 가장자리를 전부 `(34,34,34)` 로. 0x72 규칙이다.
5. **마무리** — 외곽선 칠하다 고립돼버린 픽셀 정리, 떨어져 나온 조각(6px 미만) 제거.
6. **정렬** — 접지점(맨 아래 3행의 가로 중앙)을 캔버스 바닥 중앙에 맞춰 얹었다.
   꼬리가 프레임마다 길이가 달라서 bbox 로 맞추면 몸이 흔들린다.
7. **4장 고르기** — 원본이 5장이라, 순환했을 때 프레임 간 변화 합이 가장 작은 조합을 골랐다.
   idle 은 f3, run 은 f4 를 뺐다.

## 프레임 간 흔들림

정렬 후 f0 대비 실루엣 차이가 idle 13~21%, run 14~18%.
참고로 0x72 자신은 big_demon idle 이 20~47%, ogre idle 이 6~12% 다. **정상 범위 안이다.**

## 남은 일 (코드)

이 폴더 것은 아직 게임에 연결돼 있지 않다. 넣으려면:

1. 8장을 `assets/tileset/frames/` 로 옮긴다 (`pack-sprites.js` 가 그 폴더만 읽는다).
   그 폴더는 CC0 원본 자리이므로, 출처를 섞기 싫으면 `pack-sprites.js` 의 `FRAMES` 를 손봐야 한다.
2. `tools/pack-sprites.js` 의 `CHARACTERS` 에 `dragon: 'dragon',` 한 줄.
3. `node tools/pack-sprites.js`
4. `js/actors.js` 나 `js/bosses.js` 에 몬스터/보스로 등록.

## 출처

`assets/custom/dragon_opacity2.png` 에서 파생. **원본의 출처와 라이선스는 확인되지 않았다.**
`assets/tileset/` (0x72, CC0) 와 달리 근거가 없으니, 공개 전에 확인이 필요하다.
색은 0x72 팔레트에서 가져왔다.
